It would a good experiment to check the capabilities of the system by running a Qwen-3-VL model insider a container and track the progress of the Agent in solving a task.


We need to learn to build agents with Open-weight models to implement the capabilities of complex systems with independent modules. 


Capabilities of frontier closed source models can be replicated by carefully designing the system for a particular problem.


---

AgentEvolver is an end-to-end, self-evolving training framework that unifies  - self-questioning, 

- self-navigating, and 

- self-attributing into a cohesive system. 


It empowers agents to autonomously improve their capabilities, aiming for efficient, cost-effective, and continuous capability evolution.
